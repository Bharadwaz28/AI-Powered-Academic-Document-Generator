# AI ACADEMIC DOCUMENT GENERATOR

## 1. INTRODUCTION

The AI Academic Document Generator is an intelligent content generation system that automatically creates PowerPoint presentations and PDF academic reports from a user-provided topic. The system integrates Artificial Intelligence, document generation technologies, chart visualization, and dynamic image retrieval to produce professional-quality academic documents with minimal user effort.

Unlike traditional document creation methods, the application generates structured content, visual elements, charts, tables, and images automatically, significantly reducing the time required for academic content preparation.

---

## 2. OBJECTIVES

* Automate academic document generation.
* Generate professional PowerPoint presentations and PDF reports.
* Reduce manual effort involved in content creation.
* Integrate Artificial Intelligence with document automation.
* Provide visual enhancement through charts and images.
* Improve productivity for students, researchers, educators, and professionals.

---

## 3. SYSTEM OVERVIEW

The system follows a modular architecture consisting of:

### Frontend Layer

* Streamlit-based interactive web interface.
* User input collection.
* Document preview functionality.
* Download management.

### AI Processing Layer

* Groq API integration.
* LLaMA language models.
* Content generation engine.

### Visualization Layer

* Dynamic chart generation.
* Table generation.
* Image retrieval from Unsplash.

### Output Layer

* PDF generation using ReportLab.
* PPT generation using python-pptx.

---

## 4. WORKFLOW

Step 1: User selects document type (PPT or PDF).

Step 2: User enters topic and number of sections.

Step 3: AI generates structured academic content.

Step 4: Relevant charts, tables, and images are created.

Step 5: Interactive preview is displayed.

Step 6: Document is generated and downloaded.

---

## 5. MODULES

### 5.1 User Interface Module

Developed using Streamlit.

Functions:

* Topic input
* Section selection
* Document type selection
* Preview functionality
* Download functionality

### 5.2 AI Content Generation Module

Uses Groq API and LLaMA models.

Features:

* Academic section generation
* Bullet-point generation
* JSON-based PPT content generation
* Structured PDF content generation

### 5.3 Image Retrieval Module

Uses Unsplash API.

Features:

* Dynamic image fetching
* Orientation-based image selection
* Duplicate image prevention

### 5.4 Chart Generation Module

Uses Matplotlib.

Supported Charts:

* Bar Charts
* Line Charts
* Pie Charts

### 5.5 PDF Generation Module

Uses ReportLab.

Features:

* Title page generation
* Table of contents
* Academic formatting
* Charts and images
* Page numbering

### 5.6 PPT Generation Module

Uses python-pptx.

Features:

* Multiple slide layouts
* Bullet formatting
* Automatic image placement
* Chart slides
* Table slides
